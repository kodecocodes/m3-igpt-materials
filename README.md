# Integrating ChatGPT in Your iOS Apps: Materials



This repo contains all the downloadable materials and projects associated with the [Integrating ChatGPT in Your iOS Apps](https://www.kodeco.com/ios/paths/third-party-ai/49480710-integrating-chatgpt-in-your-ios-apps) module from [Kodeco](https://www.kodeco.com).

- This course is part of [Apple Intelligence Program](https://www.kodeco.com/ios/programs/apple-intelligence), which you can take as either on-demand or live bootcamp.

--- 

Each version has its own branch, named `versions/[VERSION]`. The default branch for this repo is for the most recent version.
